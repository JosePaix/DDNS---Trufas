# Doces Do Nosso Sim - Controle de Estoque e Vendas

Aplicativo web completo para controle de estoque, cadastro de ingredientes e gestão de trufas artesanais da marca **Doces Do Nosso Sim**.

## Funcionalidades
1. **Tema Noturno com Fundo Preto e Letras Brancas**: Ao clicar no ícone de lua 🌙, o fundo fica totalmente preto e as letras tornam-se brancas. O sol ☀️ restaura o tema padrão.
2. **Formas de Pagamento**: Crédito, Débito, Pix e Dinheiro.
3. **Status de Recebimento**: Checkbox para marcar cada venda como "Recebido" ou "Pendente".
4. **Gráfico de Saída de Sabores**: Visualização em barras na aba de Relatórios.
5. **Sistema de Login Seguro**: Com bloqueio progressivo por tentativas (`paixao421` / `362514@Sa`).

## Como Executar e Publicar no GitHub
Basta abrir o arquivo `index.html` em qualquer navegador ou atualizar os arquivos no seu repositório existente do GitHub.
