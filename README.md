# Doces Do Nosso Sim - Controle de Estoque e Vendas

Aplicativo web completo para controle de estoque, cadastro de ingredientes e gestão de vendas de trufas artesanais da marca **Doces Do Nosso Sim**.

## Funcionalidades
1. **Interface de Vendas**:
   - Registro de múltiplos sabores por venda.
   - Cálculo automático com base no custo unitário (R$ 2,14) e preço de venda padrão (R$ 5,00).
   - Opção de promoção com preço e sabores customizados.
2. **Interface de Cadastros**:
   - Cadastro de ingredientes (nome, peso, validade).
   - Cadastro de lotes de trufas (sabor, data de produção, cálculo automático de validade de 10 dias, quantidade).
3. **Interface de Relatórios & Exportação**:
   - Resumo financeiro do dia, da semana e do mês (faturamento e lucro).
   - Botão para exportar todos os dados (vendas, estoque e ingredientes) para uma planilha Excel (`.xlsx`).
4. **Design**:
   - Layout elegante em tons de bege, totalmente responsivo.

## Como Executar
Basta abrir o arquivo `index.html` em qualquer navegador web moderno (Chrome, Edge, Firefox, Safari).

## Como Publicar no GitHub e Colocar Online
1. Crie um repositório público no [GitHub](https://github.com/).
2. Faça o upload dos arquivos `index.html`, `style.css`, `app.js` e `README.md` para o repositório.
3. Vá nas configurações do repositório (**Settings** > **Pages**).
4. Na seção **Build and deployment**, selecione a branch `main` (ou `master`) e a pasta `/ (root)`. Clique em **Save**.
5. Em alguns minutos, seu app estará online e acessível publicamente!
