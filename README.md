# Doces Do Nosso Sim - Versão Completa

Aplicativo mobile com layout otimizado, tema noturno (fundo preto e letras brancas), conexão MySQL (`${{ MySQL.MYSQL_PRIVATE_URL }}`), controle de vendas, estoque por ciclos de 7 dias, preço dos ingredientes, custo total de produção, total de trufas produzidas, subtração automática no estoque ao vender, e cálculo de Dízimo (10% do lucro líquido).
