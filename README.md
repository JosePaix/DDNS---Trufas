# Doces Do Nosso Sim - Controle de Estoque e Vendas

Aplicativo web completo para controle de estoque, cadastro de ingredientes e gestão de trufas artesanais da marca **Doces Do Nosso Sim**.

## Novas Funcionalidades
1. **Formas de Pagamento**: Crédito, Débito, Pix e Dinheiro.
2. **Status de Recebimento**: Checkbox interativo para marcar cada venda como "Recebido" ou "Pendente".
3. **Gráfico de Saída de Sabores**: Visualização em barras na aba de Relatórios indicando os sabores mais vendidos.
4. **Modo Noturno (Dark Mode)**: Botão alternador com ícone de Sol (modo claro) e Lua (modo noturno) posicionado abaixo do logotipo.
5. **Sistema de Login Seguro**: Com bloqueio progressivo por tentativas.

## Como Executar e Publicar no GitHub
Basta abrir o arquivo `index.html` em qualquer navegador ou atualizar os arquivos no seu repositório existente do GitHub.
