# Doces Do Nosso Sim - Controle de Estoque e Vendas

Aplicativo web completo para controle de estoque, cadastro de ingredientes e gestão de vendas de trufas artesanais da marca **Doces Do Nosso Sim**, agora com sistema de login protegido.

## Regras de Segurança de Login
- Limite de **3 tentativas incorretas**: Bloqueio automático por **30 segundos**.
- Caso o erro persista após o bloqueio: Novo bloqueio por **5 minutos**.

## Funcionalidades
1. **Sistema de Login com Proteção por Tentativas**.
2. **Interface de Vendas** (múltiplos sabores, cálculo automático, promoção personalizada).
3. **Interface de Cadastros** (ingredientes e lotes de trufas com validade automática de 10 dias).
4. **Interface de Relatórios & Exportação Excel** (.xlsx).
5. **Design Elegante em Tons de Bege**.

## Como Executar e Publicar no GitHub
Basta abrir `index.html` no navegador ou subir os arquivos para um repositório público no GitHub habilitando o GitHub Pages.
